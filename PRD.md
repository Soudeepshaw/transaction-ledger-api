## 1. Objective

A backend API for a simple transaction ledger. Users create accounts, post credit and debit transactions, and read balances and transaction history.

## 4. Non-functional requirements (my additions)

- Money is `Decimal` / `Numeric(18,2)`, never float; at most 2 decimal places.
- Balance update and transaction insert commit together or not at all.
- Concurrent requests: row lock on Postgres; unique constraint handles duplicate races.
- Transactions are immutable (no update/delete endpoints).
- Consistent error body: `{"error": <code>, "message": <text>}`.
- Runs with zero setup on SQLite; `DATABASE_URL` switches to Postgres.

## 5. Status codes

| Case | Code |
|---|---|
| Account / transaction created | 201 |
| Duplicate `reference_id` (same payload) | 200 + `duplicate: true` |
| Same `reference_id`, different type/amount | 409 |
| Unknown account | 404 |
| Insufficient balance, bad pagination, bad amount, same-account transfer | 422 |

## 6. API surface (prefix `/api/v1`)

- `GET /accounts/{id}/balance`
- `POST /accounts/{id}/transactions`
- `GET /accounts/{id}/transactions?type=&page=&limit=`
- `POST /transfers` (extra)
